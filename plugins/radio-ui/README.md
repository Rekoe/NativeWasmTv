# 动态电台界面 JAR

唱片绘制、旋转、切台动画、手势预览和唱片 PNG 位于独立 DEX JAR。
宿主保留 `RadioUi` v1 接口、加载器和简单标题界面；播放器、网络请求及封面下载仍由宿主管理。
JAR 不打包进主 APK。没有本地插件时尝试从默认 URL 下载；没有插件或下载失败时电台仍可播放。
默认地址：`https://raw.githubusercontent.com/buhanzhe/NativeWasmTv/master/plugins/radio-ui/dist/radio-ui-v4.jar`，发布产物与源码一并保存在仓库中。
高级设置支持保存自定义 URL、下载更新和手动导入；GitHub URL 使用宿主统一加速设置。

## 使用

安装本次测试 APK，在局域网管理网页打开“高级设置 → 电台界面插件”，
选择 `dist/radio-ui-v4.jar` 并导入。同一入口可以导入新版 JAR，立即替换当前界面。
正在进行手势/切台动画时，等动画完成再替换，音频播放不中断。
插件会保留在应用私有目录，后续启动离线加载，无需重复导入。

上传入口：`POST /api/radio-ui`，请求体为 JAR 原始字节；状态查询为 `GET /api/radio-ui`。
请求体上限 2 MiB。既有管理服务的访问方式不变。

## 构建

```powershell
python plugins/radio-ui/src/build.py --version 4 --sdk D:/android/sdk --java-home YOUR_JAVA8_HOME
```

需要 Android Build Tools 30.0.3（D8）和平台 android-30。
D8 以 `--min-api 14` 编译并处理 Java 8 语法；JAR 包含 `classes.dex`、
`radio-ui.json` 和 `radio/vinyl.png`，不包含宿主接口的重复定义。
实现只使用 Android API14 可用类型，新 API 保留运行时版本判断。

元数据 `api` 是接口版本，`version` 是界面版本，`minSdk` 是最低系统版本，
`entry` 类必须实现宿主 `xiao.bu.tv.radio.RadioUi`，提供 `(Context, ClassLoader)` 构造方法。
构造方法和界面生命周期运行在主线程；文件处理和 DEX 加载在后台进行。

导入前检查配置、接口、构造和资源初始化。每个 JAR 以 SHA-256 存入独立只读路径，
避免覆盖已加载的 DEX/资源。只有验证通过才切换持久化的活动版本；失败保留旧插件。
已安装文件在重新加载时再次校验哈希。这里的哈希是完整性检查，不是发布者签名。

## 柔光唱片备选样式（v3 / v4）

导入 `dist/radio-ui-v4.jar` 后，在“高级设置 → 电台界面 → 唱片样式”选择
“经典唱片（默认）”或“柔光唱片”。默认继续使用经典唱片；新版包含原唱片 PNG。
柔光样式只模拟圆形封面、十二道细环和局部反光，不提供新的播放控制界面。
元数据的 `styles` 声明样式能力，旧插件只显示经典选项。

`POST /api/radio-ui` JSON `{"style":"optical"}` 或 `{"style":"classic"}` 保存选择。
样式替换复用同一 JAR、保留封面和播放状态，在手势/切台动画完成后执行。
离线重启保留选择；导入不支持柔光的旧插件后回到经典样式。
默认下载地址指向 v4，经典唱片仍是默认样式。已经保存过旧插件地址的实例，
可在管理页换成上述地址并下载更新，也可以手动导入新版 JAR。

v3 的柔光纹理和封面在内容变化时栅格化。播放期间，封面更新硬件层旋转、
固定反光层更新透明度，`onDraw` 不分配对象，不逐帧生成 Bitmap 或进行模糊。
细环和反光固定在各自的 512×512 纹理中，封面单独以 307×307 纹理旋转，
避免细环在旋转采样时闪烁，并缩小旋转硬件层面积。这三张纹理共约 2.36 MiB
（不含 GPU 图层和原始封面）；
切台期间还会短暂持有快照/相邻封面，动画完成后解除引用。

本地测试与交付保持原包名 `xiao.bu.tv` 和正式签名，覆盖安装时保留应用数据。
通过本地静音音轨与临时电台源测试实际播放、暂停、切台、样式切换和渲染耗时。
动画时钟回调统计与 `dumpsys gfxinfo ... framestats` 分开记录；回调频率不等同于显示帧率。

### v4 动态光效

`OpticalMotionView` 使用自定义 View / Canvas 逐帧绘制十二道细环：逐环亮度传递、
两处移动的椭圆高光、微弱的蓝金色反射、背景呼吸，以及每 4.8 秒一组三道向外扩散的光圈。
光效独立于封面的 18 秒旋转；播放时运行，暂停、不可见和脱离窗口时停止回调。
这些光效按时间变化，当前不接音频频谱或节拍检测。

渐变、矩阵、画笔和裁剪路径缓存复用，逐帧不创建 Bitmap 或 Java 对象。
多层半透明描边形成柔光，不依赖旧系统硬件不支持的模糊滤镜；
硬件路径裁剪在 API18 及以上启用。封面单独缓存为 614×614，
宿主封面解码上限提高至 1024px，使用有上限的 8 MiB 图片缓存。
切台快照只在过渡期间生成。暂停键立即更新动画状态，不再等待播放器轮询。

- ARM32 / ARM64 正式签名 release 构建通过，包名保持 `xiao.bu.tv`。
- 小米 6 / Android 7.1.1：原应用内导入 v4，真实音轨播放、切台和默认封面通过。
- SM-G3608 / Android 4.4.4：原包名覆盖安装、Dalvik 加载 v4、封面与光效绘制通过；
  使用设备内的临时 HTTP 音轨验证播放，外圈两帧有 50.30% 像素变化，
  暂停并等待绘制稳定后两次截图无像素变化。未取得该机的可靠帧耗时百分位。
- 外圈区域两帧对比有 89.65% 像素变化，证明光效自身在运动；
  暂停后同一区域两次截图无像素变化。
- 该设备播放采样 8,906 帧，系统标记卡顿 291 帧（3.27%），
  帧耗时 P50 12ms、P90 15ms、P95 16ms、P99 18ms。
  此为本地音轨样本；详细光效比 v3 更耗性能，不能作为其他设备的帧率保证。
- 管理网页样式选择器回归通过。Android 9 的完整仪器回归记录属于 v3，
  不作为 v4 材质与旧机性能的实测结果。
- 两台真机测试后恢复原频道列表、源配置和显示设置，移除临时测试源；
  保留 v4 插件并选择柔光样式，新安装的默认样式仍是经典唱片。

交付 `output/soft-disc-detail-demo.mp4` 为原包名应用的 18 秒实机录像，
涵盖一圈封面旋转与多次扩散光圈；v4 JAR 需与本次主 APK 配套使用。
